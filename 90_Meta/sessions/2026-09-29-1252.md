# Sesja — rejestracja natywnych skills Antigravity

## Diagnoza
Antigravity Skill Discovery wymaga katalogu per skill z `SKILL.md` i YAML `name`/`description`. Repo miało 20 płaskich plików `.md`; tylko `kb-epistemic-solve` miało wymagany katalogowy manifest. Adapter opisywał używanie nazw jako slash invocation, lecz ta informacja nie rejestrowała skills.

## Zmiany
- Przeniesiono 20 definicji do `.agent/skills/<skill-name>/SKILL.md`; zachowano treść instrukcji i dodano opis wyzwalający.
- Usunięto dublujący płaski `kb-epistemic-solve.md`, zachowując kanoniczny folderowy skill.
- Zaktualizowano adaptery, AGENTS.md/CLAUDE.md, roadmapę i istniejące odwołania do ścieżek.
- Dodano `.agent/scripts/validate_skills.py` oraz testy; CI waliduje rejestr skills.

## Weryfikacja
- Rejestr: 20 katalogów, 0 błędów.
- Testy narzędzi z PyYAML 6.0.2: 11/11 zaliczone; walidator parsuje poprawnie wszystkie 20 manifestów.
- Lint Vaultie: 0 błędów blokujących, 5 znanych ostrzeżeń o brakujących `aliases` w MOC-ach.
- Antigravity UI nie jest dostępne w sandboxie: po pobraniu zmian rozpocznij nową sesję/odśwież workspace i sprawdź menu `/`.
